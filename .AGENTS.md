# CadE2E-Harness agent instructions

For end-to-end or fully automated CAD tests, read and follow
[`autocad-e2e`](autocad-e2e/SKILL.md) before changing or invoking a runner.

Keep the harness usable from its conventional submodule path
`tests/CadE2E-Harness`. Resolve the consuming repository root relative to the
runner location, and keep project-specific plugin and test assemblies in the
consuming repository.

Mutating tests must work on copied drawings. Require semantic PASS markers and
timestamped artifacts for every automated run.
